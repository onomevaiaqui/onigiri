# CAD do Onigiri

## Arquivo disponível

- `Onigiri.step`: modelo mecânico compartilhado do robô no formato STEP.

O formato STEP preserva a geometria para abertura e edição em ferramentas CAD compatíveis. Ele pode ser usado como referência para montagem, revisão do chassi e desenvolvimento de peças futuras.

## Uso recomendado

1. Abra o arquivo em um software CAD compatível com STEP.
2. Confirme as dimensões antes de fabricar ou alterar componentes.
3. Registre no histórico do projeto toda revisão mecânica relevante.
4. Não substitua o modelo sem indicar, no `CHANGELOG.md`, o que mudou e por quê.

## Estado

O modelo representa o chassi em desenvolvimento. Ele deve evoluir junto com a montagem física e os testes do robô.
